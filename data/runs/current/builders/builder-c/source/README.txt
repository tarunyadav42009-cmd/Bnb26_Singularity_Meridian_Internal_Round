# Rainfall Data Analysis & Statistical Prediction

## Technologies
- Python
- Flask
- Pandas
- NumPy
- Matplotlib
- HTML/CSS

## Run
1. Open a terminal in this folder.
2. Install dependencies:
   pip install -r requirements.txt
3. Start the project:
   python app.py
4. Open:
   http://127.0.0.1:5000

## Print Report
Use the **Print Report** button in the browser. The charts are generated by Matplotlib and embedded directly as images, so they remain available in the browser print preview and on paper/PDF.
